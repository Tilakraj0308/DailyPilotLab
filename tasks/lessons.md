# Lessons learned (agent workflow)

Append **short, actionable** entries when the user corrects you, CI fails for a known reason, or the same mistake happens twice. Use reverse-chronological order (newest first).

## Template

```text
### YYYY-MM-DD — <topic>
- **Pattern:** what went wrong or what we observed
- **Fix:** what we did
- **Next time:** rule to follow
```
