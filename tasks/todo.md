# Task board (agent / team)

Use this file for **multi-step** work when a checklist helps. Simple one-shot edits can skip it.

## How to use

1. **Plan** — Under “Current task”, write goal, constraints, and checkable steps.
2. **Verify plan** — For large or ambiguous work, confirm with the user before deep implementation.
3. **Track** — Check boxes as you go (`[ ]` → `[x]`).
4. **Review** — When done, add a short **Review** subsection: what changed, commands run, follow-ups.
