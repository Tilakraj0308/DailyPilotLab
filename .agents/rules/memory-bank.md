# Project Memory Bank
Always refer to the following files in the `.notes` directory to maintain project state and context:

- @.notes/active_context.md (Current focus and session state)
- @.notes/project_brief.md (High-level goals)
- @.notes/tech_stack.md (Versions and libraries)
- @.notes/progress.md (Checklist of what's done)
- @.notes/architecture.md (Data flow and folder conventions)
- @.notes/decisions.md (Architectural decisions log)

**Instructions:**
1. Before starting any task, read the `active_context.md`.
2. After completing a significant task or changing the architecture, update the relevant files in `.notes/`.
3. If you detect a conflict between my prompt and the `project_brief.md`, flag it immediately.
4. When making an architectural decision, log it in `decisions.md` with the rationale.
5. After each session, update `active_context.md` with what was accomplished and what's next.
